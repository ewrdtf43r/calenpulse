Политика конфиденциальности CalenPulse

Редакция от 2 ноября 2026 года

CalenPulse — расширение для браузера, которое показывает события Google Календаря в боковой панели и присылает напоминания в браузере, Telegram и Discord.

Какие данные обрабатываются

  • События Google Календаря — название, время, место и описание событий в календарях, отмеченных пользователем в Google Календаре. Данные читаются через официальный Google Calendar API с доступом calendar.events.
  • Список календарей — названия, цвета и доступные права календарей пользователя, чтобы показать события с цветовой маркировкой (доступ calendar.calendarlist.readonly).
  • Токены Google OAuth — access token и refresh token, полученные после явного входа в аккаунт Google.
  • Настройки уведомлений — интервалы напоминаний, токен Telegram-бота, chat id, Discord webhook.

Где хранятся данные

  • В браузере — токены и настройки лежат в chrome.storage.local на вашем компьютере.
  • На вашем сервере — если вы включили синхронизацию 24/7, refresh token и настройки каналов отправляются на сервер, адрес которого вы указали сами. Сервер шифрует эти данные при хранении (AES-256-GCM) и использует их только для опроса календаря и отправки напоминаний.

Разработчик расширения не получает и не хранит ваши данные: у расширения нет собственного облака, аналитики и телеметрии.

Передача третьим сторонам

  • Google — чтение и изменение событий через Google Calendar API.
  • Telegram — отправка текста напоминания через Bot API, если канал включён.
  • Discord — отправка текста напоминания через webhook, если канал включён.

Данные не продаются, не используются для рекламы и не передаются никому, кроме перечисленных сервисов.

Удаление данных

Кнопка «Отключить» на странице настроек удаляет токены из браузера. Чтобы удалить данные с сервера, используйте команду DELETE /api/account с вашим ключом синхронизации или удалите запись на сервере.

Разрешения расширения

  • identity — вход через Google OAuth.
  • calendar.events — чтение и изменение событий календарей пользователя.
  • calendar.calendarlist.readonly — чтение списка календарей и их цветов.
  • storage — хранение токенов и настроек локально.
  • alarms, notifications — напоминания в браузере.
  • sidePanel — интерфейс в боковой панели.
  • Доступ к адресу вашего сервера запрашивается отдельно, только когда вы включаете синхронизацию 24/7.
