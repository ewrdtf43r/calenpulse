Эти же интервалы сервер использует для Telegram и Discord.

Telegram

Создайте бота у @BotFather, напишите ему любое сообщение и узнайте chat id у @userinfobot.

Discord

Канал → «Изменить канал» → «Интеграции» → «Вебухуки» → «Новый вебхук» → скопировать URL.

Сервер 24/7

Сервер опрашивает календарь и отправляет Telegram/Discord, даже когда компьютер выключен. События и токены идут только на ваш собственный сервер.
